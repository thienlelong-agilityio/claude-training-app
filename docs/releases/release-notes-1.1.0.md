# Release notes: AI Tools - Training 1.1.0 (proposed)
Status: DRAFT, not approved. Date: 2026-11-23.

## Overview
This release adds a place to write a short note about what you shipped today, on each Capstone day page (Days 12 to 15). The note saves by itself. Copying the note for Slack is not part of this release yet.

| What | Available now? |
|---|---|
| Write a note on each Capstone day page | Yes |
| The note saves by itself and shows "Saved" | Yes |
| Character counter and a 500-character limit | Yes |
| Copy the note for Slack with one button | Not yet: planned for a later release |
| A line on the page that says where the note is saved | Not yet: planned for a later release |

## What's new
### Daily standup note
- **What it does:** On each Capstone day page (Days 12, 13, 14 and 15), next to "Mark Day X as complete", there is a box called "What I shipped today". You write a few lines about what you did. Each day has its own note, and a note shows only on its own day page. The note saves about 2 seconds after you stop typing, and you see "Saved". You can keep editing after you mark the day complete, and marking or unmarking a day never changes your note.
- **Limits:** A note can have up to 500 characters. A counter shows how many characters are left, and line breaks count as characters. At the limit, further typing is not accepted. If you paste text that is too long, only the first 500 characters are kept and a message tells you. Your note is saved in the browser you are using. It does not follow you to another browser or device, and signing in does not move it. If the browser does not let the page save, you see "Could not save your note. It may be lost if you leave this page." and your text stays on the screen.
- **How to use it:**
  1. Open a Capstone day page.
  2. Click the box "What I shipped today" and type your note.
  3. Wait about 2 seconds until you see "Saved".
  4. Come back to the same day page in the same browser later: your note is there.

## Other changes
- None.

## Known limitations
- The note stays in the browser you use. It is not available on another device or in another browser.
- The "Copy for Slack" button is not available yet.
- The page does not yet say where the note is saved.
